# 📚 Book Rating Prediction System

A Machine Learning and Data Science project that predicts book ratings using book-related features such as publication year, number of pages, and ratings count.

---

# 📌 Project Overview

This project focuses on analyzing book data and predicting the average rating of books using Machine Learning techniques.

The model learns patterns from book-related attributes and predicts book ratings based on selected input features.

The project was developed using:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab / Jupyter Notebook
